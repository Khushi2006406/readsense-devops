# ReadSense – Smart Book Recommendation System

ReadSense is a smart and personalized book recommendation system.

The system recommends books based on the user's:
- Mood
- Preferred genre
- Available reading time
- Preferred book length
- Previous ratings
- Reading history

The project demonstrates a basic DevOps CI/CD pipeline using GitHub Actions.

## Technologies Used

- Python
- GitHub
- GitHub Actions
- Pytest

## CI/CD Pipeline

The GitHub Actions pipeline automatically:
1. Checks out the source code.
2. Sets up the Python environment.
3. Installs pytest.
4. Runs automated tests.
5. Runs the ReadSense application.

## Project Goal

The goal is to provide personalized book recommendations while demonstrating
automated testing and continuous integration using GitHub Actions.
